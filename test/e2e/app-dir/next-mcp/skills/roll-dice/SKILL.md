# Rolling dice

1. Call the `roll_dice` tool with the number of sides.
2. For odds, read [references/ODDS.md](references/ODDS.md).
3. To roll many dice locally, run `scripts/roll.py`.

The d20 icon is in `assets/d20.png` (and `assets/d20.svg`).
