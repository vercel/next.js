# Next.js 中文文档

React 框架，用于生产环境。

## ✨ 特性

- ⚡ 服务端渲染 (SSR)
- 📦 自动代码分割
- 🔄 路由系统
- 📱 图像优化
- 🔥 热重载

## 🚀 快速开始

```bash
npx create-next-app@latest my-app
cd my-app
npm run dev
```

访问 http://localhost:3000

## 📖 页面示例

```tsx
// app/page.tsx
export default function Home() {
  return <h1>你好，Next.js！</h1>
}
```
