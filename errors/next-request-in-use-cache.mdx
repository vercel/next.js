---
title: Cannot access request data in `"use cache"`
---

## Why This Error Occurred

A cached function tried to access the incoming request. APIs such as `cookies()`, `headers()`, `searchParams`, and `connection()` depend on the request and cannot be called inside `"use cache"`. Draft mode can be read inside a cached function, but it cannot be enabled or disabled there.

## Possible Ways to Fix It

Read request data outside the cached function and pass the values you need as arguments. Call `connection()` and enable or disable draft mode outside the cached function as well.

Before:

```jsx filename="app/page.js" highlight={5}
import { cookies } from 'next/headers'

async function getExampleData() {
  "use cache"
  const isLoggedIn = (await cookies()).has('token')
  ...
}

export default async function Page() {
  const data = await getExampleData()
  return ...
}
```

After:

```jsx filename="app/page.js" highlight={9}
import { cookies } from 'next/headers'

async function getExampleData(isLoggedIn) {
  "use cache"
  ...
}

export default async function Page() {
  const isLoggedIn = (await cookies()).has('token')
  const data = await getExampleData(isLoggedIn)
  return ...
}
```
