---
title: Instant Navigation validation errors
---

Instant Navigation validation checks whether a route can render the UI required for its [navigation stages](/docs/app/glossary#navigation-stages). Use this page to find the error that matches the message and data source reported by Next.js.

## Debug validation errors

Start with [`next dev`](/docs/app/guides/building#find-blocking-work) and open the affected route. The development overlay and terminal show source-mapped stack frames and rerun validation as you edit.

If the error only appears during `next build`, follow [Debug prerender errors](/docs/app/guides/building#debug-prerender-errors) to enable more detailed stack traces and code frames. You can combine `--debug-prerender` with `--debug-build-paths` to focus on specific routes.
