A page or layout on this route exports [`unstable_ensureStatic`](/docs/app/api-reference/file-conventions/route-segment-config/ensureStatic) with the `'navigation'` value, requiring fully static server output.

During [prerendering](/docs/app/glossary#prerendering), `generateMetadata()` read request-specific data from `cookies()`, `headers()`, `params`, `searchParams`, or a short-lived cache. This data is not available in fully static output.

Uncached `fetch` requests, database calls, and `connection()` have different fixes. See [Uncached data in `generateMetadata()` on a route that must be fully static](/docs/messages/ensure-static-metadata-dynamic).

## Use static metadata

Replace the request-specific data with values available during prerendering:

```jsx filename="app/dashboard/layout.jsx"
export function generateMetadata() {
  return { title: 'My page' }
}

export default function Layout({ children }) {
  return <section>{children}</section>
}
```

If every value is fixed, a static [`metadata`](/docs/app/api-reference/functions/generate-metadata#metadata-object) export may be simpler.

## Provide static parameters

If metadata depends on route parameters, return the parameter values to prerender from [`generateStaticParams()`](/docs/app/api-reference/functions/generate-static-params):

```jsx filename="app/blog/[slug]/page.jsx"
export function generateStaticParams() {
  return [{ slug: 'hello' }]
}

export async function generateMetadata({ params }) {
  const { slug } = await params
  return { title: slug }
}
```

Include every dynamic parameter. An empty array does not satisfy the fully static requirement.

## Extend the cache lifetime

A cache with a short lifetime can also count as runtime data. For fully static navigation, `expire` must be at least 300 seconds, `stale` at least 30 seconds, and `revalidate` greater than zero. Increase the lifetime only when serving shared, older metadata is acceptable.

## Verifying the fix

Reload the route in [`next dev`](/docs/app/api-reference/cli/next#next-dev-options), then run [`next build`](/docs/app/api-reference/cli/next#next-build-options) and confirm that the route completes prerendering.

Wrapping the access in Suspense or setting `instant = false` does not relax the fully static requirement.

## Don't want this validation?

If the route requires request-time metadata, remove `unstable_ensureStatic = 'navigation'` from the pages or layouts that set it.
