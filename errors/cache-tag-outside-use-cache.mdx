---
title: Cannot call `cacheTag()` outside `"use cache"`
---

## Why This Error Occurred

`cacheTag()` attaches a tag to the cache entry produced by a `"use cache"` or `"use cache: private"` function so that entry can later be revalidated with `revalidateTag()`. When it is called outside a cached function there is no cache entry to tag, so the call has no effect and is not allowed.

```jsx filename="app/page.js" highlight={4}
import { cacheTag } from 'next/cache'

export default async function Page() {
  cacheTag('products') // No cache entry to tag
  return <p>...</p>
}
```

## Possible Ways to Fix It

Move `cacheTag()` inside the cached function whose entry you want to tag.

```jsx filename="app/page.js" highlight={5}
import { cacheTag } from 'next/cache'

async function getProducts() {
  'use cache'
  cacheTag('products') // Tags this cache entry
  return db.products.findMany()
}

export default async function Page() {
  const products = await getProducts()
  return <p>...</p>
}
```

If you did not intend to cache anything, remove the `cacheTag()` call. To revalidate the tag later, call [`revalidateTag()`](/docs/app/api-reference/functions/revalidateTag) from a Server Action or Route Handler.
