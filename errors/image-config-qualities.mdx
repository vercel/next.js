## Why This Error Occurred

You are using the `next/image` component with the [`quality`](/docs/app/api-reference/components/image#quality) prop, but the value is missing from [`images.qualities`](/docs/app/api-reference/components/image#qualities) in your `next.config.js` file.

## Possible Ways to Fix It

- Add the value to the [`images.qualities`](/docs/app/api-reference/components/image#qualities) array in your `next.config.js` file.
- Change the [`quality`](/docs/app/api-reference/components/image#quality) prop to 75, which is the default value and does not require additional configuration.
