---
title: Cannot call `cacheLife()` outside `"use cache"`
---

## Why This Error Occurred

`cacheLife()` sets how long the cache entry produced by a `"use cache"` or `"use cache: private"` function stays fresh (its `stale`, `revalidate`, and `expire` times). When it is called outside a cached function there is no cache entry whose lifetime it could configure, so the call is not allowed.

```jsx filename="app/page.js" highlight={4}
import { cacheLife } from 'next/cache'

export default async function Page() {
  cacheLife('hours') // No cache entry to configure
  return <p>...</p>
}
```

## Possible Ways to Fix It

Move `cacheLife()` inside the cached function whose lifetime you want to set.

```jsx filename="app/page.js" highlight={5}
import { cacheLife } from 'next/cache'

async function getProducts() {
  'use cache'
  cacheLife('hours') // Configures this cache entry
  return db.products.findMany()
}

export default async function Page() {
  const products = await getProducts()
  return <p>...</p>
}
```

If you did not intend to cache anything, remove the `cacheLife()` call.
