A page or layout on this route exports [`unstable_ensureStatic`](/docs/app/api-reference/file-conventions/route-segment-config/ensureStatic) with the `'navigation'` value, requiring fully static server output.

During [prerendering](/docs/app/glossary#prerendering), `generateMetadata()` performed an uncached `fetch` request, database call, or `connection()`. The operation requires request-time server work and cannot be included in fully static output.

Request-specific reads from `cookies()`, `headers()`, `params`, or `searchParams` have different fixes. See [Runtime data in `generateMetadata()` on a route that must be fully static](/docs/messages/ensure-static-metadata-runtime).

## Cache the metadata

When the metadata can be shared across requests, cache `generateMetadata()` with [`use cache`](/docs/app/api-reference/directives/use-cache) and choose an appropriate [`cacheLife`](/docs/app/api-reference/functions/cacheLife) profile:

```jsx filename="app/page.jsx"
import { cacheLife } from 'next/cache'

export async function generateMetadata() {
  'use cache'
  cacheLife('hours')
  const response = await fetch('https://api.example.com/content')
  const data = await response.json()
  return { title: data.title }
}
```

This fix does not apply to [`connection()`](/docs/app/api-reference/functions/connection), whose purpose is to require request-time rendering.

## Use static metadata

If the metadata does not need the uncached value, replace it with data available during prerendering:

```jsx filename="app/dashboard/layout.jsx"
export function generateMetadata() {
  return { title: 'My page' }
}
```

If every value is fixed, a static [`metadata`](/docs/app/api-reference/functions/generate-metadata#metadata-object) export may be simpler.

## Verifying the fix

Reload the route in [`next dev`](/docs/app/api-reference/cli/next#next-dev-options), then run [`next build`](/docs/app/api-reference/cli/next#next-build-options) and confirm that the route completes prerendering.

Wrapping the operation in Suspense or setting `instant = false` does not relax the fully static requirement.

## Don't want this validation?

If the route requires request-time metadata, remove `unstable_ensureStatic = 'navigation'` from the pages or layouts that set it.
