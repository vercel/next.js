The experimental `agentFeedback` option enables an opt-in review flow for de-identified Next.js reports prepared by AI coding agents. The option is off by default and works independently from [Next.js Telemetry](/telemetry).

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  experimental: {
    agentFeedback: true,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    agentFeedback: true,
  },
}

module.exports = nextConfig
```

## How agent feedback works

When `next dev` detects an AI coding agent, Next.js adds a short managed block to your project's `AGENTS.md` or `CLAUDE.md`. The block points to version-matched reporting instructions bundled with your installed Next.js version.

The protocol tells the agent when to prepare feedback and how to structure one reproducible Next.js report. The agent opens a review form but cannot submit it. You can edit the report, remove individual details, close the form without sending, or select **Send feedback**.

Only the reviewed report, agent name, and Next.js version are sent. The form does not attach project files or machine metadata.

`agentFeedback` works independently from the top-level [`agentRules`](/docs/app/guides/ai-agents#opting-out) option. Changing one option does not affect the other.

## Disable agent feedback

Set `experimental.agentFeedback` to `false` or remove the option. The next `next dev` run removes only the managed `<!-- BEGIN:nextjs-agent-feedback -->` block. Next.js preserves all other content in `AGENTS.md` and `CLAUDE.md`.
