Enable experimental Markdown output for routes that opt into `text/markdown` responses.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    markdown: true,
  },
}

module.exports = nextConfig
```

## Good to know

- This flag enables the Markdown runtime, but routes must still opt in with `export const markdown = true` or `export const markdown = { components: ... }`.
- Markdown is only returned for full document `GET` and `HEAD` requests that prefer `text/markdown`.
- RSC requests, prefetch requests, and data requests keep their existing response formats.
- The feature works in both App Router and Pages Router when the route runs in the Node.js runtime.
- Edge runtime routes ignore Markdown negotiation and continue to return their normal responses.
