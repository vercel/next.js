The `webpack` key in `next.config.js` lets you extend the webpack config Next.js generates. It applies only to builds that opt into webpack with the `--webpack` flag, since [Turbopack](/docs/turbopack) is the default bundler.

This reference now lives with the rest of the webpack documentation:

- [webpack configuration](/docs/webpack/configuration) for the config function, its arguments, and examples
- [webpack](/docs/webpack) for when to use webpack and what changes when you do
