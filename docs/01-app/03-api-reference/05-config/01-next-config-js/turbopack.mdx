The `turbopack` key in `next.config.js` lets you customize how [Turbopack](/docs/turbopack) transforms files and resolves modules. A set of experimental `turbopack*` options control minification, tree shaking, chunking, and caching.

This reference now lives with the rest of the Turbopack documentation:

- [Turbopack configuration](/docs/turbopack/configuration) for module rules, loaders, aliases, and resolution
- [Experimental options](/docs/turbopack/configuration#experimental-options) for the full option list and its defaults in dev and build
