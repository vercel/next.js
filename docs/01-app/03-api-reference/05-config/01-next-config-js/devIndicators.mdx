---
title: devIndicators
description: Configure the position and visibility of the Next.js development indicator with devIndicators.
---

Use `devIndicators` in `next.config` to set the initial position of the Next.js development indicator or hide it when idle.

See the [Next.js DevTools guide](/docs/app/guides/devtools) to open DevTools, move the indicator, and collapse diagnostic badges.

## Position

Set `devIndicators.position` in `next.config.ts` to choose where the indicator initially appears. The default is `bottom-left`.

```ts filename="next.config.ts"
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  devIndicators: {
    position: 'bottom-right', // 'bottom-left' | 'bottom-right' | 'top-left' | 'top-right'
  },
}

export default nextConfig
```

To move the badge from the browser, use the [Position preference](/docs/app/guides/devtools#position) or drag the Next.js logo.

## Hide the indicator

To hide the idle indicator, set `devIndicators` to `false`. Compile errors, runtime errors, and Insights still appear, and you can open the DevTools menu whenever a diagnostic badge is visible. To hide the indicator temporarily from the browser, use [Show indicator](/docs/app/guides/devtools#show-indicator) in Preferences.

```ts filename="next.config.ts"
const nextConfig: NextConfig = {
  devIndicators: false,
}

export default nextConfig
```

## Troubleshooting

### Indicator not marking a route as static

See [Route information in DevTools](/docs/app/guides/devtools#route-information) for the Static/Dynamic label and how it relates to Cache Components.
