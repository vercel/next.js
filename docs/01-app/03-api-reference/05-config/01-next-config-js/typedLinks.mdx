---
title: typedLinks
description: Enable statically typed links.
---

Support for [statically typed links](/docs/app/api-reference/config/typescript#statically-typed-links). This feature requires using the App Router as well as TypeScript in your project.

```js filename="next.config.js"
/** @type {import('next').NextConfig} */
const nextConfig = {
  typedLinks: true,
}

module.exports = nextConfig
```
