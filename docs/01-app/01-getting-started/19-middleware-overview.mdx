# Getting Started with Next.js Middleware

This page provides an overview of using middleware in Next.js applications.

## Overview

Next.js middleware allows you to run code before a request is completed.

## Basic Usage

Create a `middleware.ts` file in the root of your project:

```typescript
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'

export function middleware(request: NextRequest) {
  return NextResponse.next()
}
```
