Welcome to the Next.js documentation!

This **Getting Started** section takes you from creating a new Next.js project to deploying it, while introducing the core concepts behind the App Router.

## How the App Router works

An App Router application is a tree of React components defined by files and folders in the `app` directory. Layouts and pages are Server Components by default, so they can fetch data and render on the server without adding their component code to the browser. Add Client Components where you need state, event handlers, or browser APIs.

Next.js prerenders as much of each route as possible. Give reusable data or UI a cache lifetime so it can be included in a shell or prefetch, and place request-time work behind Suspense so it can stream when needed. Use Server Functions to mutate data and refresh or revalidate the affected UI.

The pages that follow build on that model as they cover routing and navigation, error handling, styling, metadata, Route Handlers, and deployment.

## Pre-requisite knowledge

Our documentation assumes some familiarity with web development. Before getting started, it'll help if you're comfortable with:

- HTML
- CSS
- JavaScript
- React

If you're new to React or need a refresher, we recommend starting with our [React Foundations course](/learn/react-foundations), and the [Next.js Foundations course](/learn/dashboard-app) that has you building an application as you learn.
