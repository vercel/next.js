Use Next.js DevTools to inspect errors, route information, and loading states while running `next dev`. Configure the indicator's initial position and visibility with [`devIndicators`](/docs/app/api-reference/config/next-config-js/devIndicators) in `next.config`.

## Open DevTools

Click the Next.js logo (**N**) to open the DevTools menu. The logo appears in the bottom-left corner by default. From the menu, you can view route information, open [Preferences](#preferences), or inspect how your app loads:

- Use the [Navigation Inspector](/docs/app/guides/instant-navigation#visualize-loading-states-with-the-nextjs-devtools) to pause page loads and navigations while you inspect loading states. It requires [Cache Components](/docs/app/api-reference/config/next-config-js/cacheComponents).
- Use **Request Insights** to inspect request timelines, server fetches, and cache activity. It requires `experimental.requestInsights`. Coding agents can read the same data using the [Next.js MCP runtime tools](/docs/app/guides/mcp#runtime-tools).

## Inspect diagnostics

Click the red **Issues** or amber **Insights** button beside the logo to open its tab. The **Diagnostics** entry in the menu shows both counts and opens the overlay.

Insights can point to work that prevents a route from loading instantly. See [Instant Navigation validation messages](/docs/messages/instant-navigation-validation) for examples and [Fixing a navigation that blocks](/docs/app/guides/instant-navigation#fixing-a-navigation-that-blocks) for a walkthrough.

## Route information

Without Cache Components, the **Route** entry shows whether the current route is **Static** ([prerendered](/docs/app/glossary#prerendering)) or **Dynamic** ([rendered at request time](/docs/app/glossary#dynamic-rendering)). Click it for an explanation. You can also check the route output from [`next build --debug`](/docs/app/api-reference/cli/next#next-build-options).

With [Cache Components](/docs/app/getting-started/cache-components), the Static/Dynamic marker is hidden because a route can combine prerendered content with content rendered at request time. Use the [Navigation Inspector](/docs/app/guides/instant-navigation#visualize-loading-states-with-the-nextjs-devtools) to inspect loading states instead.

## Move the badge

If the badge covers part of your app, close any open DevTools panels and drag the Next.js logo to another corner. You can also choose a corner under [**Position**](#position) in Preferences. Set [`devIndicators.position`](/docs/app/api-reference/config/next-config-js/devIndicators#position) in `next.config` to choose the starting corner for the project.

## Collapse the badge

Click the chevron (**‹**) at the end of the badge to collapse it to the Next.js logo. The diagnostic count stays visible. Click the logo to expand the badge, then click it again to open the menu.

If the idle indicator is hidden, **×** dismisses the diagnostic badge until a new diagnostic appears. Build errors stay visible until you fix them.

## Show indicator

Turn off **Show indicator** in Preferences to hide the idle badge and dismiss the current diagnostic. New errors and Insights still appear, and build errors stay visible.

To bring the badge back, click **Undo** on the confirmation, use your [shortcut](#keyboard-shortcut), or restart the dev server. You can also reopen Preferences from a new diagnostic and turn **Show indicator** back on. To hide the idle badge for the whole project, set [`devIndicators: false`](/docs/app/api-reference/config/next-config-js/devIndicators#hide-the-indicator) in `next.config`.

### Keyboard shortcut

Click **Record shortcut** in Preferences and press a key combination. Once it shows **Saved**, press the same keys to show or hide the indicator.

## Preferences

Open **Preferences** from the DevTools menu to change how DevTools look and behave.

### Theme

Use your system theme, or choose **Light** or **Dark**.

### Position

Choose any of the four corners. Dragging the Next.js logo updates the same setting. See [`devIndicators.position`](/docs/app/api-reference/config/next-config-js/devIndicators#position) for the configuration values.

### Size

Choose **Small**, **Medium**, or **Large** for the badge and DevTools panels.

### Restart dev server

Restart the development server from the browser.

### Reset bundler cache

Clear the bundler cache and restart the dev server. Use this if you see stale errors or your changes don't appear.
