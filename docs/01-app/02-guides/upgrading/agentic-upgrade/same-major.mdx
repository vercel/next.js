Use the exact target version in the handoff prompt. Do not run a codemod or
follow a major-version migration guide for this same-major update.

## Install

- [ ] Install the exact target Next.js version. Update other dependencies if
      needed for compatibility.

## Verify

- [ ] Confirm the installed version with `next --version`.
- [ ] Verify the app works with the updated dependencies and resolve any issues
      caused by the update.

## Deliver

- [ ] After verifying the version update and any requested Future Defaults
      adoption, return to `shared.md` and complete its delivery checklist.
