CONTENT MANAGEMENT SYSTEM (VERY IMPORTANT)

The website must be fully editable after deployment without requiring programming knowledge.

Implement a modern CMS with a visual editing experience.

Requirements:

• All texts must be editable.
• Headlines must be editable.
• Images must be replaceable.
• Hero images must be editable.
• Products can be added, removed and updated.
• Prices can be changed easily.
• Product descriptions are editable.
• Blog/Journal articles can be created and published.
• Homepage sections can be reordered.
• Future products (Rising Sun, Daylight, Sundowner, Night) can be activated later without rebuilding the website.
• Contact information must be editable.
• Footer links must be editable.
• Legal pages must be editable.
• SEO titles and meta descriptions must be editable.
• Open Graph images must be editable.
• Favicon and Logo can be replaced easily.

Use reusable components throughout the website.

All sections should be built as modular blocks.

The website must support future expansion without redesigning the structure.

The online shop must allow adding new products, categories and limited editions.

Provide a clean admin interface for content management.

The website should be maintainable by the owner without developer support.
