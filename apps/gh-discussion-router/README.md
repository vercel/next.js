# GitHub Discussion Router

Note that the initial version of this has predominantly been generated by Claude.

A Next.js app that helps users find existing GitHub discussions or create new ones based on string similarity matching.

## Features

- Search for discussions in a configured GitHub repository
- String similarity matching using Dice's Coefficient
- Server-side rendering for better performance and security
- Display matching discussions with similarity scores
- Direct links to create new discussions with pre-filled content

## Setup

1. Install dependencies:
```bash
pnpm install
```

2. Create a `.env.local` file:
```bash
cp .env.example .env.local
```

3. Configure environment variables:
   - `GITHUB_TOKEN`: Create a personal access token at https://github.com/settings/tokens/new with `repo` or `public_repo` scope
   - `GITHUB_REPO`: Repository to search (e.g., `vercel/next.js`)

4. Run the development server:
```bash
pnpm dev
```

5. Open http://localhost:3000

## Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `GITHUB_TOKEN` | Yes | - | GitHub Personal Access Token |
| `GITHUB_REPO` | Yes | - | Repository in `owner/repo` format |
| `SIMILARITY_THRESHOLD` | No | `0.4` | Minimum similarity score (0-1) |
| `MAX_DISCUSSIONS_TO_FETCH` | No | `100` | Max discussions to fetch |

## How It Works

1. User enters a discussion title and optional description
2. App fetches recent discussions from the configured repository
3. Similarity algorithm compares the input against existing discussions:
   - 70% weight on title similarity
   - 30% weight on body similarity (if description provided)
4. Displays matching discussions above the threshold
5. If no good matches, shows button to create new discussion

## Tech Stack

- **Next.js 16.0.8**: App Router with Server Components
- **TypeScript**: Type-safe development
- **Tailwind CSS v4**: Styling
- **Octokit**: GitHub API client
- **string-similarity-js**: String matching algorithm
- **Zod**: Environment variable validation
