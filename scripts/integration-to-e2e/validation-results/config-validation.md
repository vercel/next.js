## Warnings

- `test/production/config-validation/config-validation.test.ts:10-13`: `if (!isNextStart) { it('skipped', () => {}); return }` is inside a describe that already called `nextTestSetup()`. Per conversion guidance this anti-pattern runs setup unnecessarily; also unreachable in `test/production/`. Consider removing the guard entirely.
- `test/development/config-validation/index.test.ts:6-19`: Uses inline `files: { ... }` instead of a fixture directory with `__dirname`. Acceptable for tiny fixtures, but guidance prefers real fixture directories.
- The development file tests a new behavior ("validation only runs once") not present in the original. This is additional coverage — not a regression, but worth noting it is not a direct conversion.
