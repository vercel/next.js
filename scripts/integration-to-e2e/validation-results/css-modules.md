## Warnings

- `if (!isNextStart) { it('skipped for non-start mode', () => {}); return }` placed _inside_ describes that already call `nextTestSetup()`. Since the file lives in `test/production/`, `isNextStart` is always true and the guard is unreachable. The checklist's 4c guideline discourages this pattern because it would still run the nextTestSetup harness; here it's safe but redundant — removing the 11 placeholders would clean up dead code.
