## Issues

None (no fail-level problems).

## Warnings

- The original test's point was verifying `next build <dir>` CLI behavior by running build from a parent directory and pointing at a `build/` subdirectory containing the app. The converted version just calls `next.build()` on a standard fixture and thereby no longer exercises the custom-directory CLI argument. Consider asserting a custom directory path is passed to build/start, or documenting that the feature is covered elsewhere.
- `expect(result.stderr).toBe('')` was replaced with `expect(result.exitCode).toBe(0)` — weaker check (stderr warnings won't fail).
- Dedup guard `process.env.TURBOPACK_DEV ? describe.skip : describe` was dropped. The `isNextStart` early-return still instantiates `nextTestSetup()` in dev mode. Prefer wrapping at the describe level outside `nextTestSetup`.
