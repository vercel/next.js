## Warnings

- **3d / 7a**: Uses `nextBuild` from `next-test-utils` directly against `path.join(next.testDir, 'app')` instead of `next.build()`. This is likely required because the monorepo fixture builds from the `app/` subdirectory (not `testDir` root) so the trace can pick up `../other/included.txt`. Document or revisit whether `next.build()` can be configured with a cwd/subdir option.
- **4c**: The `if (!isNextStart) { it('skipped for non-start mode', () => {}); return }` early-return inside a `describe` that calls `nextTestSetup()` is the pattern explicitly warned against in criterion 4c. Since the file lives in `test/production/` (which only runs in start mode), the guard is unnecessary and should be removed. If a Turbopack-build skip is ever needed, wrap with `;(process.env.IS_TURBOPACK_TEST ? describe.skip : describe)(...)` OUTSIDE `nextTestSetup`.
