## Warnings

- The `if (!isNextStart) { it('skipped for non-start mode', () => {}); return }` guard inside a describe that calls `nextTestSetup()` mirrors the anti-pattern called out in criterion 4c. Since this file lives in `test/production/`, `isNextStart` is always true, so the guard and stub test are dead code. Remove both.
- Potential `cliOutput` accumulation: `next.cliOutput` may contain output from prior `next.build()` runs in the same describe. A later test checking for a specific error message could succeed due to earlier output. Consider capturing output length before each build (`const offset = next.cliOutput.length`) and asserting on the slice, or using `await next.build()` return values if available.
- The original had a `TURBOPACK_DEV` dedup guard on the outer describe; the converted file drops it. Acceptable because `test/production/` only runs in start mode, but worth confirming CI matrix doesn't double-run.
