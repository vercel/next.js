## Warnings

- L67-70: direct `fs.readFile(join(next.testDir, '.next/server/pages/...'))` — prefer `next.readFile('.next/server/pages/...')`.
- `webdriver(port, path)` still used throughout shared.ts and test file; prefer `next.browser(path)`.
- `fetchViaHTTP(ctx.appPort, ...)` could be replaced with `next.fetch(path, opts)`; acceptable since port-extraction works.
- Original dedup env-var guards (`TURBOPACK_BUILD`/`TURBOPACK_DEV`) dropped; covered implicitly by nextTestSetup mode selection.
- The "error configs" block accumulates `next.cliOutput` across tests; each test checks a distinct message so no false positives, but the pattern is brittle.
