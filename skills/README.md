# Published Skills

This directory contains skills intended for external distribution. They are not
repo-local Codex skills for this checkout.

Use `.agents/skills/` for skills that should be loaded by agent sessions inside
this repo. Do not require `skills/` entries to be referenced from `AGENTS.md` or
to appear in this repo's rendered Codex prompt.

When reviewing files in this directory, treat sibling skills and bundled
`scripts/`, `references/`, and other assets as part of the published skill
bundle.
